Longer Technical Defense

The revised pipeline is easier to defend technically than a synthetic-only one.

The main point is that synthetic data is a means, not a principle. It is valuable when relevant labeled data are scarce or unavailable. But once a more domain-aligned corpus exists, insisting on fully synthetic training can become harder to justify. In this case, ALPUB_v2 provides real ancient Greek uncial exemplars. That matters because the target problem is not generic character recognition, but learning visually meaningful structure from historically relevant letterforms.

A synthetic-only pipeline has several technical weaknesses:

- It encodes strong prior assumptions about what the target domain should look like.
- Those assumptions are made by the pipeline designer, not learned from the data.
- Errors in those assumptions can propagate directly into the model.
- The model may learn the simulator's artifacts rather than the real domain's structure.

That does not make synthetic generation useless. It means synthetic generation is best treated as controlled augmentation or corruption, not necessarily as the sole source of truth.

The revised pipeline improves this in three ways:

- It uses real uncial source images rather than wholly synthetic exemplars.
- It preserves document-level metadata, allowing train/validation splitting by source document.
- It applies degradation on the fly to real images, which preserves the utility of controlled corruption without forcing the model to learn entirely from simulated glyphs.

The weighting change is also defensible. The dataset remains unchanged. You are not oversampling to a uniform corpus, deleting common classes, or rewriting labels. You are using mild inverse-square-root sampling to reduce gradient domination by frequent classes. That is a conservative training intervention, not a claim that the true class distribution is balanced.

The key distinction is:

- full inverse-frequency balancing pushes hard toward an artificial training distribution
- inverse-square-root weighting is a softer correction that still respects the original skew

So the revised pipeline is not "less real" because it uses weighting. It is more realistic overall because it combines:

- real uncial exemplars
- label normalization
- document-level splitting
- mild, explicit sampler correction
- synthetic degradation only as augmentation

If challenged, the strongest line is:

"The revised pipeline reduces modeling risk by moving the source of supervision closer to the actual target domain, while keeping synthetic corruption only where it is useful and controlled."
